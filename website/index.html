Commands

Docker as always.
One small command for the rest.

Use docker and docker compose exactly as you know them. To manage lindowin itself:

lindowin status      Is Docker running? Containers, memory, disk, updates
lindowin update      Latest lindowin and Docker CLI, keeping your settings
lindowin stop        Free the memory now (containers shut down cleanly)
lindowin compact     Give unused disk space back to Windows
lindowin config      idle-sleep, start-at, share, network
lindowin uninstall   Keeps your containers and data (--all deletes them)

How it works

The same idea as Docker Desktop.
Without the app.

Three small, open pieces. You can read every line.

Docker Engine in WSL 2

A small Ubuntu distro runs the open-source Docker Engine, started by systemd and kept up to date.

Official CLI on Windows

docker.exe, compose and buildx from their official sources, checksums verified.

A tiny relay

Connects them through Docker Desktop's pipe. Compiled on your PC: no prebuilt binaries, no TCP port.

Requirements: Windows 10 2004+ / Windows 11 (Home works) or Windows Server 2022 / 2025, x64, virtualization enabled. Read the README · Español
